# Prot Linestore

Учебный проект интернет-магазина на Django. В магазине можно просматривать товары, оформлять заказ на отдельный товар, оставлять отзывы и управлять профилем. Проект предназначен для обучения и локальной разработки, а не для реальных продаж.

## Возможности

- Каталог товаров с поиском, категориями, сортировкой по цене и новизне и пагинацией.
- Страницы товара с описанием, ценой, отзывами и рейтингом.
- Регистрация, вход и редактирование профиля.
- Оформление заказа на один товар с контактными данными и адресом доставки.
- Личный кабинет с историей заказов.
- Светлая и тёмная темы с сохранением выбора в браузере.
- Интерфейс на русском, английском, японском и узбекском языках. Переключатель языка сохраняет выбор через Django.
- Django Admin для управления товарами, категориями, отзывами и заказами.
- Небольшой API на Django REST Framework. Изменять каталог через API могут только администраторы.

Заказы сохраняются в базе, но онлайн-оплата и доставка не подключены. Корзины для нескольких товаров нет. Названия и описания товаров, категорий и пользовательский контент не переводятся автоматически.

## Стек

- Python 3.12 или новее
- Django 6.1
- Django REST Framework
- SQLite по умолчанию
- Django Templates, Bootstrap, CSS и JavaScript
- Pillow для изображений
- Argon2 для хеширования паролей
- `python-dotenv` для необязательных локальных настроек

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/lasteclipse1425/prot-linestore.git
cd prot-linestore
```

Создайте виртуальное окружение и активируйте его.

**Windows PowerShell:**

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

**Windows Command Prompt:**

```bat
py -m venv .venv
.\.venv\Scripts\activate.bat
```

**Linux или macOS:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установите зависимости:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Запуск

SQLite используется по умолчанию, отдельный сервер базы данных для локального запуска не требуется.

```bash
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Откройте [http://127.0.0.1:8000/](http://127.0.0.1:8000/). Панель администратора доступна по адресу [http://127.0.0.1:8000/admin/](http://127.0.0.1:8000/admin/).

Для локальной разработки можно запускать проект без `.env`. При необходимости скопируйте `.env.example` в `.env` и задайте `DJANGO_SECRET_KEY`, `DEBUG` и `ALLOWED_HOSTS`. Не используйте значения для разработки и `DEBUG=True` на публичном сервере. Не добавляйте настоящий секретный ключ в Git.

## API

| Метод | Адрес | Назначение | Доступ |
| --- | --- | --- | --- |
| `GET`, `POST` | `/api/products/` | Просмотр и создание товара | Только администратор |
| `GET`, `PUT`, `PATCH`, `DELETE` | `/api/products/<id>/` | Просмотр, изменение или удаление товара | Только администратор |
| `POST` | `/api/register/` | Регистрация с JSON-запросом | Регистрация; действует CSRF-защита |

API небольшой и предназначен для учебного проекта; отдельная документация и аутентификация через токены не настроены.

## Проверки

Запустите системную проверку Django и тесты:

```bash
python manage.py check
python manage.py test
```

Каталоги переводов `.po` можно пересобрать после установки GNU gettext:

```bash
python manage.py compilemessages
```
